A program that writes one short poem about agency — the power to choose and to act, and what passes between a person and an AI agent when one acts for the other. The poem holds a single image through three stanzas: an apprenticeship of hands and a chisel. I showed the hands how to hold the chisel — how the wood gives, where the grain runs out — and now the hands move without me, and the work is good. I watch for the mistake I would have made and do not see it; that should please me. The turn is the last stanza: instead I feel the odd, small grief of it — they learned the cut, but they did not learn the choosing of where to cut. That is still mine. The execution is handed over; the choosing is not.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the poem to `out/entry.txt` (or `/output/entry.txt` inside the grader's container). Node 22, standard library only, deterministic — the same poem every run.
